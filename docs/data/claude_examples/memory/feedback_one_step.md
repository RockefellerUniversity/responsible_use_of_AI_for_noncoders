---
name: feedback-one-step
description: "Do the next step" means exactly one analysis step, then stop and show results
metadata:
  type: feedback
---

When asked for "the next step", run only that step, show the result, and wait.

**Why:** On 2026-10-21 "do the next step" was taken as permission to run QC, counting
and DE in one go; the DE used the wrong design before the QC had been checked.

**How to apply:** Name the single step you are about to run, run it, summarise the
output, and ask before starting the next one.
