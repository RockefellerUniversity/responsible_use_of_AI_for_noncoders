# Writing style

No `paths:` frontmatter, so this rule loads in every session, like CLAUDE.md.

- UK spelling (leukaemia, haematopoietic, analyse).
- Gene and protein names: human gene *IKZF1* (italic, capitals), mouse gene *Ikzf1*, protein Ikaros.
- Short sentences. Explain jargon the first time it appears.
- Numbers: give units and the sample size (e.g. "5-year EFS 53%, n = 991").
